# 業務邏輯首頁範本

本次輸出資料夾的 `business.md` 依下面的範本撰寫，`gen-html.sh` 會把它轉成 `index.html`。

- 第一個 `#` 標題會成為首頁大標題，寫本次開發的主題。
- 四個 `##` 章節固定保留，順序不變。
- 只能用：`#`～`###` 標題、`- ` 清單、表格、code block、段落、行內 code、粗體。`gen-html.sh` 的 markdown renderer 不支援編號清單、連結、引用區塊與巢狀清單。
- 從程式碼與對話判斷不出來的內容寫 `TODO：<缺什麼>`，產 HTML 前和使用者確認；不得自行編造。

---

```markdown
# <本次開發主題>

## 目的
<為什麼要做這次開發，要解決什麼問題>

## 需求
- <需求來源：需求單、會議或對話>
- <具體要做到的事>

## 業務邏輯
### 哪些資料會出現
- <欄位或資料，以及它代表的意義>

### 什麼時候出現或消失
| 情境 | 結果 |
|---|---|
| <條件> | <資料出現、消失或變化> |

## 前端要改什麼
- <要呼叫哪些 API、在什麼時機呼叫>
- <畫面或欄位的調整>
- <需要特別處理的錯誤回應>
```
